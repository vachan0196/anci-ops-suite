# Design Documents — Proposed, Not Authoritative

This directory holds **proposed** design documents. Nothing in this folder is
authoritative, regardless of how detailed or how recently reviewed.

Only entries in `DECISIONS.md` marked **Accepted** are binding.

Where a design document in this folder disagrees with `DECISIONS.md`, `DECISIONS.md`
wins.

A design document may describe wider context, options considered, or a rationale that
informed a decision, but its presence here is not adjudication. A decision does not
become authoritative because an AI wrote it down; it must survive independent review
and Vachan's judgement, and be recorded as Accepted in `DECISIONS.md` before it governs
anything.
